## [1.0.0] - 2026-01-19

### Added

- Initial release
- `get-commit-messages` reusable workflow for retrieving recent commit history
- Formatted output for Microsoft Adaptive Cards with time-ago timestamps
- Configurable commit count (default: 10)
- JSON output with linked commit messages and author attribution
